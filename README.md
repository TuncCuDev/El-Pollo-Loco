# El Pollo Loco

A 2D browser game built with JavaScript, inspired by classic side-scrolling platform games. Players control Pepe, collect coins and bottles, defeat enemies, and face the final boss in an action-packed desert adventure.

## Features

* Side-scrolling gameplay
* Character movement, jumping, and throwing mechanics
* Multiple enemy types
* Collectible coins and bottles
* Final boss battle
* Health, coin, and bottle status bars
* Sound effects and animations
* Responsive game interface

## Technologies

* HTML5
* CSS3
* JavaScript (ES6)
* Object-Oriented Programming (OOP)
* Canvas API

## Gameplay

### Controls

| Key         | Action       |
| ----------- | ------------ |
| Arrow Left  | Move Left    |
| Arrow Right | Move Right   |
| Space       | Jump         |
| D           | Throw Bottle |

### Objectives

* Defeat enemies
* Collect coins
* Collect throwable bottles
* Avoid taking damage
* Defeat the final boss to win the game
